## UX placement rationale
The section sits between **Services** and **Why Alphasonic**. This gives visitors the sequence:
**understand the services → see evidence of work → understand the working principles → estimate the project → contact the business**.

The gallery uses mostly white, navy and neutral surfaces so the project photography adds credibility without increasing brand-colour noise. The original logo, slogans, favicon and other supplied brand artwork are unchanged.
